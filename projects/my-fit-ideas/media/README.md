# Portfolio Media and Demonstration Plan

This folder is reserved for approved public-facing media that demonstrates the My Fit Ideas capstone without exposing source code, credentials, tokens, private records, or other sensitive information.

## Planned Media

The portfolio may include:

- A dashboard screenshot showing current weight, hydration, BMI, and latest measurement
- A progress-chart screenshot showing selectable date ranges
- A hydration chart demonstrating missing-date handling
- A simplified architecture diagram
- A database relationship diagram
- A short demonstration video showing registration, login, measurement entry, hydration entry, profile settings, dashboard summaries, and progress charts
- Selected testing evidence with sensitive information removed

## Publication Checklist

Before adding any file, confirm that:

1. Personal email addresses and user records are removed or replaced with demonstration data.
2. Passwords, JWT values, secrets, database connection strings, and environment variables are not visible.
3. Browser tabs, bookmarks, notifications, and developer tools do not expose unrelated private information.
4. Captions explain what each image demonstrates.
5. Images are readable at normal page width.
6. Meaningful alternative text or accompanying descriptions are provided.
7. Every media item reflects the implemented capstone scope and does not imply unimplemented functionality.

## Current Status

The documentation structure is complete. Public screenshots, diagrams, the final report, and the demonstration video will be added after final review and redaction.
